# Homebrew Tap for FERRIC

Official Homebrew tap for [**FERRIC**](https://github.com/debsahu/ferric) — an open-source Rust + WebGPU workbench for protein NMR resonance assignment, spin dynamics, analytical 1D/qNMR, DOSY, untargeted metabolomics, and 2D chemical depiction.

## Install

```bash
brew tap debsahu/tap

# CLI (macOS Apple Silicon, macOS Intel, Linux x86_64)
brew install ferric

# macOS Desktop Workbench (FERRIC.app + ferric CLI)
brew install --cask --no-quarantine ferric
```

## Upgrade

```bash
brew update
brew upgrade ferric
brew upgrade --cask ferric
```
